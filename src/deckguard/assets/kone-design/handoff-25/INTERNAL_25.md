# Internal 25 — as built

Built and complete in `Internal 25 v2.dc.html`. This supersedes the proposal
version in `kone-brand-mode/INTERNAL_25.md`, which described the set before it
was drawn.

Canvas 1280×720. Safe margin 45px. Content column 1190px wide, flush to x:1235.
Footer chrome (`12 MARCH 2026 · KONE INTERNAL`, KONE Information 11px
uppercase, `left:45 top:658`) on every slide except 01, 04, 05, 06 and 25.
Each slide also carries a centred archetype caption at `top:658` — that is
scaffolding for review and should be dropped in production.

Sample content is a fictional regional programme, "People Flow Intelligence".
The structure is the deliverable; the copy is placeholder.
