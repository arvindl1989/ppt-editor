# KONE master slide layouts

Exact geometry of every layout in the master template (`uploads/master_ppt-1784774200983.pptx`), extracted from the source. Reproduce any of these in HTML to match the master deck.

## Grades

Archetypes are graded A–D in **`ARCHETYPES.md`** — the canonical vocabulary (one `UPPER_SNAKE` name per archetype, engine aliases, what each is for, which are built). Read that first to choose a layout; read this file for its geometry.

- **Grade A** — most used, referred to commonly. The core twelve, built into `KoneDeck.dc.html`.
- **Grade B** — important. Build from the geometry below on demand.
- **Grade C** — somewhat important. Occasional need, or a colour/mirror variant.
- **Grade D** — good to have. Specialist layouts and the master twins.


## Grid

**Canvas:** 1280 × 720 px (16:9). **Margins:** 45px left/top. **Logo:** 81 × 31px — top-left (x:45) on covers, section dividers and end slides; top-right (x:1153) on content/agenda. **Tagline** ("Dedicated to People Flow™"): bottom-right (x:1102 y:633, 133 × 45). **Footer:** date bottom-left (x:45 y:658), page number bottom-right (x:1167 y:658), KONE Information uppercase. All positions are x, y (top-left origin), w, h in px.
